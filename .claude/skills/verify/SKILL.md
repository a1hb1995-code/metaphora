---
name: verify
description: 하네스 검증 게이트와 스모크 테스트를 실행하고 결과를 보고한다. "검증해줘", "테스트 돌려줘", 커밋/PR 직전에 사용.
---

1. `harness/check.sh` 실행 (전체, 빌드 포함).
2. `harness/smoke.sh` 실행.
3. 실패가 있으면 첫 번째 실패의 원인을 파악해 고치고 1번부터 다시. 같은 실패가 3번 반복되면 멈추고 원인 분석과 함께 사용자에게 보고한다.
4. 결과 보고 형식:

```
게이트: PASS/FAIL (단계별)
스모크: PASS/FAIL
수정한 것: ...
```
